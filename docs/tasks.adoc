= oxmonad Tasks
:toc: left
:toclevels: 2

Features still to implement, derived from the reference xmonad config
(`resources/xmonad.hs`) and xmobar config (`resources/xmobarrc`). oxmonad is a
Wayland-only reimplementation, so X11-specific items are marked N/A with a
rationale.

== Already implemented (for reference)

* Wayland compositor on smithay (winit + headless + TTY/DRM backends).
* Multi-monitor support with hotplug, one workspace per monitor.
* Workspaces `1`–`9` with view (`Mod+1..9`) and move (`Mod+Shift+1..9`);
  per-workspace layout state.
* Dynamic workspaces (`XMonad.Actions.DynamicWorkspaces`) driven by a built-in
  prompt (`XMonad.Prompt` style, `myXPConfig` colors, prefix completion, Tab
  cycling): select/create (`Mod+v`), move window (`Mod+m`), copy window
  (`Mod+Shift+m`, windows can live on several workspaces), rename
  (`Mod+Shift+r`), remove-and-merge (`Mod+Shift+BackSpace`).
* Toggle to the most recently hidden workspace (`Mod+Shift+z`, `toggleWS`).
* Swap workspaces between screens (`Mod+z`, `swapNextScreen`); focus/send to
  next/previous physical screen (`Mod+[Shift+]Left/Right`,
  `XMonad.Actions.PhysicalScreens`, screens ordered top-to-bottom then
  left-to-right); refresh (`Mod+n`).
* The full `myLayout` ring with per-layout state, `Mod+Space` cycle and
  `Mod+Shift+Space` reset: `reflectHoriz tiled ||| tiled ||| Mirror tiled |||
  noBorders Full ||| tabbed ||| Mirror Grid ||| Grid ||| ThreeCol |||
  reflectHoriz ThreeCol` (tiled = `ResizableTall 1 (3/100) (3/5)`,
  ThreeCol = `ThreeCol 1 (3/100) (1/2)`), ported from the Haskell sources.
* Layout messages: master ratio (`Mod+h`/`Mod+l`), per-tile resize
  (`Mod+Up`/`Mod+Down`, `MirrorExpand`/`MirrorShrink`), master count
  (`Mod+,`/`Mod+.`, `IncMasterN`).
* Window stack: focus next/prev (`Mod+j`/`Mod+k`), swap down/up
  (`Mod+Shift+j`/`Mod+Shift+k`), swap master (`Mod+Return`), close
  (`Mod+Shift+c`).
* Floating windows: drag-to-float (move grab), sink (`Mod+t`), floats render
  above the tiled layer.
* Manage rules: `manageZoomHook` — Zoom main/meeting windows tile and swap out
  of the master slot, all other Zoom windows float (matched on
  app-id/title at first commit).
* Window borders with focused/normal colors; suppressed on `noBorders Full`.
* Built-in status bar: workspace tags with the current one highlighted as
  `<n>` (`ppCurrent` yellow), current layout name (default `ppOrder`), focused
  window title (`ppTitle` green, shortened), toggle with `Mod+b`
  (`toggleStrutsKey`).
* Tabbed layout tab strip with the default xmonad `Theme` colors.
* Spawns: terminal (`Mod+Shift+Return`, alacritty), launcher (`Mod+p`, tofi),
  editor (`Mod+x`, emacs), locker (`Mod+Shift+l`, swaylock), media keys via
  `playerctl` (`XF86Audio*`).
* `wlr-layer-shell`, `xdg-shell`, `xdg-decoration`, `wlr-screencopy`.
* Golden-image snapshot tests for the bar, prompt and tab strip.

== Status bar

The built-in bar covers the xmonad pretty-printer side; the xmobar-specific
modules are still open.

* [ ] Clock / date module (`Run Date "%Y.%m.%d-%u %H:%M"`).
* [ ] Battery module with charging/charged/low states and color thresholds (`Run Battery`).
* [ ] Left/right alignment regions with a separator (`alignSep = "}{"`, template `%StdinReader% }{ %battery% | %date%`).
* [ ] Bar positioning/width options (config uses `TopW L 90` — top, left, 90% width).
* [ ] A proper font renderer (the built-in bitmap font is uppercase-only ASCII).

== Window management

* [ ] Fullscreen toggle for the focused window (xdg fullscreen requests).
* [ ] Scratchpad / named-scratchpad support (referenced via the `"NSP"` workspace).
* [ ] Float-window resize via `Mod+drag` (client-initiated resize grabs work already).

== Multi-monitor

* [ ] Split a single screen into virtual screens (`Mod+Shift+s`,
  `layoutSplitScreen 2 (TwoPane …)`) and `rescreen` (`Mod+Ctrl+Shift+s`).
  Deliberately deferred: it requires monitors to map to output *regions*
  rather than outputs, which touches every layout/bar/focus path — revisit if
  actually missed in daily use.

== Configuration

* [ ] Runtime/user configuration to replace the hardcoded `config.rs`
  (keybindings, colors, modifier, terminal, launcher).
* [ ] Configurable modifier — the reference config uses `mod1Mask` (Alt);
  oxmonad currently hardcodes Super (change `META` in `config.rs`).
* [ ] Configurable color theme (the config defines a full palette).
* [ ] Configurable fonts (prompt, tabs, bar — config uses `Fira Mono`).

== Not applicable (Wayland-only)

* `setWMName "LG3D"` — an X11 hack to fix Java AWT/Swing apps; not relevant under Wayland.
* `dmenu_run` / X11 launchers — already replaced by a Wayland layer-shell launcher (tofi).
* `slock` — X11-only; the lock binding spawns `swaylock` instead.
* xmobar itself — replaced by the built-in compositor-drawn bar.
* EWMH hooks (`XMonad.Hooks.EwmhDesktops`) — X11 protocol; Wayland foreign-toplevel
  management could fill this niche later if a taskbar/pager is wanted.
